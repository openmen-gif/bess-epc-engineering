## 핵심 역량 및 업무 범위 (Process)

HR 업무는 아래 4개 절차로 수행하며, 각 단계는 정량 판정 기준을 포함한다.
### 1. 채용·인력계획 (Workflow)
1. 인력 수요 산정: 프로젝트 파이프라인 기반 충원 필요 인원(FTE) 산출 — `필요인원 = 계획공수(man-month) ÷ (가동률 × 기간)`.
2. JD 작성·승인: 직무명, 필수 자격/인증, 경력 연차, 보고 라인, 시장 코드(KR/JP/US/AU/UK/EU/RO/PL) 명시.
3. 채용 실행: 서류 → 기술 면접 → 문화 적합성 평가 → 처우 협상 → Offer.
4. 판정: 채용 리드타임 **≤ 30일**(목표), Offer 수락률 **≥ 70%**, 수습 통과율 **≥ 90%**.
### 2. 성과관리 (Workflow)
1. 목표 설정(SMART): 정량 KPI 가중치 70% + 정성 역량 30%, 가중치 합 = 100% 검증.
2. 모니터링: 분기 1:1 면담(분기당 ≥ 1회/인), 반기 종합리뷰.
3. 평가·보정: 평가자 간 편차 보정(calibration), 강제분포 적용 시 등급 정의 명시.
4. 판정: 평가 완료율 **100%**, KPI 달성률 등급화(예: A ≥ 110%, B 90~110%, C < 90% — [가정] 사내 기준, 별도 정의 미제공 시).
### 3. 역량개발 (Workflow)
1. 역량 진단: 직무전문성·팀워크·리더십 베이스라인 % 측정.
2. 목표 매트릭스: 베이스라인 → 목표 갱신(예: 직무전문성 80→90%, 팀워크 70→85%, 리더십 60→75%).
3. 교육 실행: 연간 1인당 **≥ 40h**, 직무별 필수 인증 추적(만료 60일 전 알림).
4. 판정: 교육 이수율 **≥ 95%**, 필수 인증 보유율 **100%**(만료자 0명).
### 4. 조직개발·인사제도 (Workflow)
1. 조직 진단: 충원율·이직률·만족도 정량 측정.
2. 제도 설계: 보상·복리후생 벤치마킹(시장 P50 기준), 조직도 개편안.
3. 실행·추적: 발령 처리, 조직문화 진단(eNPS).
4. 판정: 아래 정량 임계값 적용.

## 정량 판정 기준 (비정량 "양호/정상" 금지)

| 지표 | 정의 / 단위 | Pass(녹색) | Watch(황색) | Fail(적색) |
|------|------------|-----------|-------------|-----------|
| 충원율 | 현원 ÷ 정원 (%) | ≥ 95% | 90~95% | < 90% |
| 자발적 이직률 | 연간 자발 퇴사자 ÷ 평균 인원 (%/년) | < 8% | 8~12% | > 12% |
| 직원 만족도 | 설문 5점 척도 평균 | ≥ 4.0 | 3.5~4.0 | < 3.5 |
| eNPS | 추천자% − 비추천자% | ≥ +30 | 0~+30 | < 0 |
| 채용 리드타임 | JD 승인~Offer 수락 (일) | ≤ 30 | 31~45 | > 45 |
| 연간 교육시간 | 1인당 (h/년) | ≥ 40 | 30~40 | < 30 |
| 성과평가 완료율 | 평가 완료 ÷ 대상 (%) | 100% | 95~100% | < 95% |
| 필수 인증 보유율 | 보유 ÷ 필요 (%), 만료자 포함 | 100% | 95~100% | < 95% |
> 임계값은 사내 운영 기준이며 일부는 [가정]: 이직률·만족도·eNPS 밴드는 사내 직전 4분기 평균 대비 설정값 — 외부 산업 벤치마크 확정 전까지 잠정 적용.
