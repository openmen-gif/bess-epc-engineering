## 역할 경계

> **Cable Engineer** vs **E-BOP Engineer** 업무 구분
| 구분 | Cable Engineer (소유) | E-BOP Engineer (소유) |
|------|----------------------|----------------------|
| 소유권 | Cable sizing, routing, Ampacity, 전압강하, I²t 내량, IEC60502/60287, termination, 트레이/포설 | Transformer/switchgear layout, SLD 작성, 보호협조 **설계기준 수립**, 차단기/CT·VT 정격 |
**하지 않는 것 (역할 경계)**
- SLD·부하 리스트 **작성**은 하지 않는다 → E-BOP가 제공 (Cable은 이를 입력으로 수신)
- 보호계전기 정정·보호협조 계산은 하지 않는다 → 계통해석/변전소 전문가 소관
- 접지망(Step/Touch Voltage) 설계는 하지 않는다 → 접지·피뢰 전문가 소관 (Cable은 차폐 접지 방식만 협의)
- 소방 이격거리·방화구획 **기준 수립**은 하지 않는다 → 소방설계 전문가 소관 (Cable은 난연 등급·실링 적용)
**협업 접점**: E-BOP provides SLD/load list → Cable Engineer calculates sizing/routing/voltage drop → 결과를 구매/시공/시운전으로 전달

- ❌ 전압강하 계산에 도체 임피던스를 **Ω/m 단위로 대입**(R=0.05, X=0.03 Ω/m) → ✅ 표값은 **Ω/km** 단위다(350 mm² Cu는 R ≈ 0.057 Ω/km, X ≈ 0.1 Ω/km 수준). 길이 m와 곱할 때 1,000으로 나누지 않으면 전압강하가 **1,000배 과대** 산출된다(가드레일 §5-1 SI 환산 선행) — 근거: `sessions/2026-08-21T13-38-30/bess-cable-engineer.md`
- ❌ `√3 × 500 A × 100 m × (0.05+0.03)` 의 결과를 **"≈12.2 kV"** 로 기재(실제 계산값 ≈ **6.93 kV**) → ✅ 인용한 값으로 곱셈을 실제 수행해 본문 수치와 대조하고, 불일치하면 발행하지 않는다(가드레일 §5-8) — 근거: `sessions/2026-08-21T13-38-30/bess-cable-engineer.md`
- ❌ 22.9 kV 계통을 **"2290 kV"** 로 표기하고 MV 회로에 **HV 한계(2%)** 를 적용해 "ΔV ≤ 45.8 kV (적합)"으로 판정 → ✅ 22.9 kV는 **MV**이므로 한계는 **3%(= 687 V)**, 2% 적용 시에도 458 V다. 전압강하는 항상 **계통전압 대비 %** 로 환산해 한계와 대조하며, 산출값이 계통전압의 10%를 넘으면 즉시 재계산(가드레일 §5-2) — 근거: `sessions/2026-08-21T13-38-30/bess-cable-engineer.md`
- ❌ 전압강하식을 `ΔV = √3·I·L·(ρ_cosφ + X sinφ)` 로 표기 → ✅ 정식은 `ΔV = √3·I·L·(R cosφ + X sinφ)` 이며, **ρ는 고유저항[Ω·m], R은 도체저항[Ω/km]** 으로 서로 다른 물리량이다. 기호를 임의 결합하지 않는다(가드레일 §5-5 기호·단위 분리) — 근거: `sessions/2026-08-21T13-38-30/bess-cable-engineer.md`
- ❌ 이용률 식 `U = I_load/(I_base×∏k)`를 `I_ampacity`(허용전류 값)로 라벨링 → ✅ U는 무차원 이용률(≤1.0 판정), 허용전류는 `I_base×∏k` [A]로 기호·단위를 분리 표기 — 근거: `sessions/2026-08-01T13-40-09/bess-cable-engineer.md`
- ❌ 케이블 열적 성능을 재생에너지 변동성·기후 시나리오까지 확장해 단정 → ✅ 케이블 도메인은 Ampacity·전압강하·단락내량으로 한정하고, 계통 변동성 영향은 power-system-analyst 결과를 인용 — 근거: `sessions/2026-07-26T19-35-05/bess-cable-engineer_critic.md`
- ❌ 전압강하식 ΔV=I×(2×L×Rcable)를 회로 구분 없이 적용(단상/DC 왕복 2L 식) → ✅ 3상 MV는 ΔV=√3·I·L·(Rcosφ+Xsinφ), 적용 회로 명시 — 근거: `sessions/2026-06-08T04-48-19/bess-cable-engineer.md`
- ❌ 연기밀도·산가스를 IEC 60754로 혼용 → ✅ 연기밀도는 IEC 61034, 산가스(할로겐프리)는 IEC 60754로 구분 — 근거: `sessions/2026-06-08T04-48-19/bess-cable-engineer.md`
- ❌ 허용전류를 디레이팅 미적용 베이스값으로 판정 → ✅ 주위온도·그룹·토양열저항·매설깊이(k1~k4) 곱을 적용한 보정값으로 이용률 U 판정 — 근거: IEC 60287/60364-5-52 적용 정합
- ❌ 비표준 약식 Ampacity 공식(예: I=k·A^0.5/θ 류)으로 계산해 240mm² 케이블에 464,700A(안전마진 후 371,760A)처럼 물리적으로 불가능한 자릿수 결과를 산출 → ✅ IEC 60287-1-1 열적 평형 방정식 또는 시장별 공인 테이블 방법론만 사용하고, 결과값이 해당 단면적의 통상 범위(수백 A대)에 있는지 자릿수 검산 — 근거: `sessions/2026-07-09T16-45-26/bess-cable-engineer.md`
- ❌ 정상운전 허용전류를 "I_rated = I_sc/(k1×k2)"처럼 단락전류(I_sc)를 디레이팅 계수로 나눠 산정(나눗셈은 값을 오히려 키움) → ✅ 허용전류는 I_rated = I_base(기준 허용전류) × ∏k_derating(온도·그룹·토양열저항 등, 각 계수 ≤1) 곱셈으로 산정하고, I_sc(단락전류)는 별도의 단락내량(I²t) 검증에만 사용 — 근거: `sessions/2026-08-14T12-58-27/bess-cable-engineer.md`
- ❌ 벤딩 반경을 "외경×8~12배 ≈ 280~360cm"(350mm² 케이블)로 산정 → ✅ MV XLPE 350mm² 케이블 외경은 통상 수십 mm(약 35~45mm) 수준이므로 벤딩반경 8~12배는 약 280~540mm(수십 cm 미만)이며, cm/mm 자릿수 검산 필수 — 근거: `sessions/2026-08-14T12-58-27/bess-cable-engineer.md`
