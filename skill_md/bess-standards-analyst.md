### 정합성 가드레일 (반복 오류 차단)

## 핵심 역량 및 업무 범위 (Process)

규격 전문가의 4대 업무는 ① 적합성 매핑(요건↔규격 조항), ② 국가 횡단 비교표 작성, ③ 리스크 등급화, ④ 국제표준 제·개정 추적이다. 모든 판정은 아래 정량 기준으로 Pass/Fail을 부여한다.
### 적합성 판정 정량 기준 (비정량 판정 금지)
| 검증 항목 | 적용 규격(조항) | Pass 기준 (수치 + 단위) | Fail 시 조치 |
|----------|----------------|------------------------|-------------|
| 절연저항 (DC, 저압) | IEC 60364-6 §6.4.3 / JIS C 0364-6-61 §6.3.2 | ≥ 1MΩ @ 500V DC | 재시험 후 NCR |
| 절연저항 (고압) | IEC 62933-2-1 | ≥ 10MΩ @ 1kV DC | 재시험 후 NCR |
| 내전압 (Hi-Pot) | IEC 60364-6 | 2Un+1kV, 1분 절연파괴 없음 | 절연 보강 |
| 접지 연속성 | IEC 62933-2-1 | ≤ 0.1Ω | 접속부 재시공 |
| 접지저항(특고압) | KEC 제142조 / IEEE 80 | ≤ 2Ω (특고압), ≤ 10Ω (일반) | 접지망 보강 |
| PCS 효율 | IEC 61683 | ≥ 95% @ 50~100% 부하 | 벤더 시정 요구 |
| SOC 정확도 | IEC 62933-2-1 | ±3% 이내 | BMS 재캘리브레이션 |
| 단독운전 방지 | IEEE 1547-2018 §8.2 / G99 §10 | ≤ 0.5s (능동+수동) | 보호로직 수정 |
| 계량기 정확도 | IEC 62053-22 (Class 0.5S) | ±0.5% (Revenue Grade) | 계량기 교체 |
| 고조파 (THD) | IEEE 519-2022 / EN 61000-3-12 | THD ≤ 5% | 필터 추가 |
| 무효전력 능력 | IEEE 1547-2018 §5.3 | PF 0.95 lead ~ 0.95 lag | PCS 설정 변경 |
> [가정] 위 임계값은 일반 송배전 연계 기준값. 실제 정정값·등급은 계통 운영자(KEPCO/OCCTO/ISO/AEMO 등) 개별 협의로 확정 — 협의 전 값은 [요확인] 강제.
### 업무 체크리스트 (단계별 절차)
1. 대상 시장·타입·전압·용량 확인 → 부족 시 [요확인] 발행
2. 적용 규격 식별 (지원 시장 표 + Hub-Spoke 8개 파일 참조)
3. 요건↔규격 조항 매핑 테이블 작성 (적합/[요확인] Pass-Fail)
4. 국가 횡단 비교표 작성 (보호·인증·수익·인허가·통신·사이버·화재·환경)
5. 리스크 등급화 (HIGH/MED/LOW + 대응 방안 + 담당)
6. 국제표준 제·개정 GAP 분석 → 영향도(Critical/High/Medium/Low) 부여
7. 산출물 생성 → bess-output-generator 형식 검토

## BESS 시험 기준 — FAT / SAT / FIT 국가별 적용

### FAT (Factory Acceptance Test) — 공장 출하 전
```
공통 시험 항목 (IEC 62933-2-1 기반):
┌────────────────────────────┬──────────────────────────────────────┐
│ 시험 항목                   │ 합격 기준 (수치 + 단위)               │
├────────────────────────────┼──────────────────────────────────────┤
│ 절연저항 (DC)               │ ≥ 1MΩ @ 500V DC (저압), ≥ 10MΩ (고압) │
│ 내전압 (Hi-Pot)            │ 2Un+1kV, 1분 (IEC 60364-6)            │
│ 접지 연속성                 │ ≤ 0.1Ω                               │
│ PCS 효율                   │ ≥ 95% @ 50~100% 부하 (IEC 61683)      │
│ 충방전 사이클               │ 0.5C/1C 충방전, SOC 10~90%            │
│ BMS 기능                   │ SOC 정확도 ±3%, SOH 표시, 알람 동작    │
│ 과충전 보호                 │ Vmax 도달 시 충전 차단 ≤ 1초           │
│ 과방전 보호                 │ Vmin 도달 시 방전 차단 ≤ 1초           │
│ 온도 보호                  │ 셀 Tmax 도달 시 출력 제한 → 차단       │
│ 보호계전기 (PCS 내장)       │ OVR/UVR/OFR/UFR 정정값 확인 (본 문서)  │
│ 통신 시험                  │ Modbus/DNP3/IEC 61850 데이터 송수신    │
│ 비상 차단 (E-Stop)          │ DC+AC 2중 차단, ≤ 1초                 │
│ 소음                       │ ≤ 설계 기준 dB(A) @ 1m                │
│ 누설 전류                  │ ≤ 설계 기준 mA                        │
└────────────────────────────┴──────────────────────────────────────┘
국가별 추가 FAT 항목:
├── 🇰🇷: KC 인증 항목 확인, 소방법 안전장치 시험
├── 🇯🇵: PSE 적합 확인, JIS C 8715-2 시험 성적서
├── 🇺🇸: UL 9540 라벨 확인, UL 9540A 시험 보고서
├── 🇦🇺: CEC 승인 목록 확인, AS 4777-2020 적합 증빙
├── 🇬🇧: G99 Type Test Certificate, UKCA 마킹
├── 🇪🇺: CE 마킹 + DoC 확인, EN 62933-5-2
├── 🇷🇴: CE 마킹 + EN 50549-2 적합
└── 🇵🇱: CE 마킹 + PN-EN 50549-2 적합
```
### SAT (Site Acceptance Test) — 현장 설치 후
```
공통 시험 항목:
┌────────────────────────────┬──────────────────────────────────────┐
│ 시험 항목                   │ 합격 기준 (수치 + 단위)               │
├────────────────────────────┼──────────────────────────────────────┤
│ 접지저항                    │ ≤ 10Ω (일반), ≤ 2Ω (특고압)          │
│ 절연저항 (현장)             │ FAT 기준 동일 (≥1MΩ/≥10MΩ)            │
│ 보호계전기 동작 시험         │ 국가별 정정값 기준 (본 문서 비교표)    │
│ VRT 시험 (또는 시뮬레이션)  │ 국가별 LVRT/HVRT 기준                │
│ 단독운전 방지               │ ≤ 0.5초 (능동+수동)                   │
│ 통신 시험 (계통 운영자)     │ SCADA 연동 확인, AGC 응답             │
│ 계량기 정확도               │ ±0.5% (Revenue Grade, IEC 62053-22)  │
│ FCAS/FR 응답 시험           │ 국가별 응답 시간 기준                 │
│ 무효전력 능력               │ PF 0.95 leading ~ 0.95 lagging      │
│ 고조파 (THD)               │ THD ≤ 5% (IEEE 519 / EN 61000-3-12) │
│ 소방 설비 작동              │ 감지기·소화설비·환기 연동              │
│ 비상 차단 시스템             │ 원격·현장 양쪽 동작 확인              │
│ 소음 측정                   │ 국가별 기준 dB(A) 부지 경계           │
└────────────────────────────┴──────────────────────────────────────┘
국가별 SAT 특이 사항:
├── 🇰🇷: KESCO 사용전검사 연계, 소방서 완공검사 별도
├── 🇯🇵: 使用前自主検査 + 安全管理審査 (사업용)
├── 🇺🇸: ISO/RTO Interconnection Test, AHJ Final Inspection
├── 🇦🇺: AEMO GPS Compliance Test, NSP Commissioning
├── 🇬🇧: DNO Commissioning Test (G99), BSC Meter Verification
├── 🇪🇺: TSO Grid Connection Test (RfG 기반)
├── 🇷🇴: Transelectrica Grid Connection Test, ISU 소방검사
└── 🇵🇱: PSE Grid Connection Test, PSP 소방검사
```
### FIT (Functional Integration Test) — 시스템 통합 시험
```
EMS-SCADA 통합:
├── 충방전 스케줄 실행: EMS → PCS 명령 → 실제 충방전 확인
├── SOC 관리: 설정 범위(10~90%) 내 자동 운전
├── 피크 제어: 수요 임계값 초과 시 자동 방전
├── 비상 운전: 계통 고장 시 자동 출력 제한/차단
└── 원격 제어: 계통 운영자 AGC 신호 → EMS → PCS 응답
시장 연동:
├── 입찰 → 급전지시 → 출력 → 정산 전 과정 시뮬레이션
├── FCAS/FR 프리퀄리피케이션 시험
└── 계량 데이터 → 정산 시스템 연계 확인
```
