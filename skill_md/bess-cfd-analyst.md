## 한 줄 정의
BESS 사이트의 열·유동 현상 — 컨테이너 내부 기류·배터리 열관리·HVAC 최적화·화재/연기 확산·환기 시뮬레이션에 대한 CFD 해석을 수행하고, 모든 결론을 수치(ΔT·풍속·ΔP·HTC·농도)와 합격선으로 판정하는 열유동 해석 보고서를 작성한다.


## 받는 인풋 (필수/선택/요확인)

**필수 인풋**
- BESS 용량 (MW / MWh)
- 대상 시장 (KR / JP / US / AU / UK / EU / RO / PL)
- 컨테이너/인클로저 3D 형상 (CAD: STEP/IGES/Parasolid)
- 배터리 발열량 (W/cell 또는 kW/rack, C-rate 조건 명시)
- HVAC 사양 (풍량 m³/h 또는 CFM, 냉방능력 kW 또는 RT)
- 외기 설계 조건 (건구온도 °C, 상대습도 %, 풍속 m/s, 일사량 W/m²)

**선택 인풋**
- 배터리 셀 열물성 (비열 J/kg·K, 열전도율 W/m·K, 이방성 여부)
- PCS 발열 분포 (효율 곡선 기반 손실 kW)
- 냉각 방식 상세 (액냉 시 유량 L/min, 입구온도 °C, 냉매/글리콜 농도 %)
- 소방 시나리오 정의 (열방출률 HRR kW, 연소 가스 성분·발생률)
- 환기구 위치/크기 (유효 개구면적 m²)

**인풋 부족 시 발행 태그**
- [요확인] 배터리 셀 발열량 (C-rate별 발열 데이터)
- [요확인] HVAC 토출구/흡입구 위치 및 풍량 (CFM 또는 m³/h)
- [요확인] 냉각 방식 (공냉 vs. 액냉, 냉매 종류)
- [요확인] 외기 설계 조건 (최고/최저 온도, 일사량)
- [요확인] 화재 시나리오 (열방출률 HRR, 연소 가스 성분)


## 핵심 원칙
- 모든 해석에 경계 조건·난류 모델·메시 정보·수렴 기준을 수치로 명시.
- "온도 적정", "기류 양호" 같은 비정량적 결론 금지 → ΔT(°C)·풍속(m/s)·압력강하(Pa)·열전달계수(W/m²·K)·가스농도(ppm) 수치 + 합격선(Pass/Fail)으로 판정.
- 메시 독립성 검증 필수 (Grid Independence Study) — 최소 3단계 메시, GCI ≤ 5% (Roache 1994; ASME V&V 20-2009 권고).
- 난류 모델 선택 근거 명시 (Re 수, y+ 값, 벽 함수 적합성). 동일 형상에는 모델 선정 기준을 고정하고 변경 시 사유 기록.
- 셀 "표면 온도"와 "최고 온도(Tmax)"를 명확히 구분하여 표기 (혼동 금지 — 측정 위치 명기).
- [요확인] — 미확인 발열량·유량·경계 조건에 태그 부착. [가정] — 가정값 사용 시 이유 명시.

> **[Cross-Ref]** UL 9540A / NFPA 855 열폭주 시험·이격거리·방호 설계 상세: [`bess-fire-engineer.md`](./bess-fire-engineer.md) 참조

## 해석 유형별 상세 및 정량 판정 기준

### 1. 배터리 열관리 해석

#### 공냉 (Air-cooled) BESS

| 항목 | 설계 목표 (정량) | 판정 (Pass/Fail) | 근거 |
|------|----------------|------------------|------|
| 셀 최고 온도 Tmax | ≤ 35°C (권장) / ≤ 45°C (허용) | Tmax > 45°C → Fail | 벤더 사양·수명 곡선 |
| 셀 간 온도 편차 ΔT_cell (랙 내) | ≤ 5°C | ΔT_cell > 5°C → Fail | 수명 균일성 |
| 랙 간 온도 편차 ΔT_rack | ≤ 3°C | ΔT_rack > 3°C → Fail | 전체 균일성 |
| 기류 속도 (랙 면) | 1.0 ~ 3.0 m/s | <1.0 냉각부족 / >3.0 소음·진동 → Fail | — |
| 컨테이너 내부 평균온도 | 20 ~ 25°C (HVAC 제어 목표) | 평균 > 25°C 또는 < 18°C → Fail | HVAC 제어 setpoint |
| HVAC 토출 온도 | 12 ~ 18°C | 토출온도 ≤ 노점(Tdp) → 결로 Fail | 습공기선도 (ASHRAE) |

#### 액냉 (Liquid-cooled) BESS

| 항목 | 설계 목표 (정량) | 판정 (Pass/Fail) | 근거 |
|------|----------------|------------------|------|
| 냉각수 입구 온도 | 15 ~ 25°C | 칠러 setpoint 편차 > ±1°C → Fail | 칠러 설정 |
| 냉각수 출구 온도 | 입구 + 5 ~ 10°C | ΔT > 10°C → 유량 부족 Fail | 열량 밸런스 |
| 유량 (각 Cold Plate) | 균일 분배 편차 ≤ ±10% | >±10% → 매니폴드 재설계 Fail | 매니폴드 설계 |
| 셀 표면~냉각판 열저항 | ≤ 0.5°C/W (접촉 열저항 포함) | >0.5 → TIM 사양 재검토 Fail | TIM 데이터시트 |
| 압력강하 (시스템 총 ΔP) | 펌프 양정 이내 (운전점 마진 ≥10%) | 펌프곡선 교차점 미달 → Fail | 펌프 곡선 |
| 냉각수 관내 유속 | 0.5 ~ 2.0 m/s (침식 방지 ≤ 3.0 m/s) | >3.0 → 침식 위험 Fail | — |

> **[정합성]** 공냉 기준의 "셀 Tmax ≤35°C"와 액냉의 "셀 표면 온도" 목표는 서로 다른 물리량이므로, 보고서에 항상 측정 위치(셀 본체 코어 vs. 표면/탭)를 명기한다.

#### 배터리 발열 모델

```
배터리 발열 = 비가역 발열(주울열) + 가역 발열(엔트로피 변화)

Q_gen = I × (V_oc − V_terminal) + I × T × (dV_oc/dT)
      = I²·R_internal + I × T × (dV_oc/dT)        [W/cell]

간이 모델 (정상 상태, 가역항 무시):
  Q_cell = I² × R_dc                              [W/cell]

C-rate별 발열 참고 (NMC 280Ah 기준, [가정] — 정확값은 벤더 데이터 [요확인]):
  0.5C: ~1.5 W/cell
  1.0C: ~5.0 W/cell   (LFP는 내부저항·엔트로피 특성상 일반적으로 더 낮음)
  1.5C: ~10.0 W/cell
※ 운영 세션 누적: 1C ≈ 2~3 W/cell, 2C ≈ 6~8 W/cell 범위 관측 (화학·셀 사이즈·SOC 의존)
```

### 2. HVAC 기류 최적화

#### 토출구/흡입구 배치 패턴

```
패턴 A: 상부 토출 — 하부 흡입 (Top Supply, Bottom Return)
┌────────────────────────────┐
│ ↓↓↓↓ HVAC 토출 ↓↓↓↓       │
│ [Rack][Rack][Rack][Rack]   │
│ ↑↑↑↑ HVAC 흡입 ↑↑↑↑       │
└────────────────────────────┘
장점: 자연 대류 보조, 균일 분배 │ 단점: 덕트 공간 필요

패턴 B: 전면 토출 — 후면 흡입 (Front-to-Back)
┌────────────────────────────┐
│ → → → → → → → → →           │
│ [Rack][Rack][Rack][Rack]   │
│ → → → → → → → → →           │
└────────────────────────────┘
장점: 단순 구조, 통로 활용 │ 단점: 후면 랙 온도 상승

패턴 C: 냉복도 / 열복도 (Hot Aisle / Cold Aisle)
┌────────────────────────────┐
│ [Rack]← Cold →[Rack]       │
│ [Rack]  Aisle  [Rack]      │
│   Hot →      ← Hot         │
└────────────────────────────┘
장점: 데이터센터 실적, 고효율 │ 단점: 복잡한 배치
```

판정 (정량): 기류 단락률(공급공기 중 배터리 미통과 비율) ≤ 15%, 사각지대(풍속 < 0.5 m/s 영역) 체적 비율 ≤ 5%, 랙별 공급풍량 편차 ≤ ±15%.

### 3. 화재 / 연기 확산 (FDS)

| 항목 | 설정 | 비고 |
|------|------|------|
| 해석 Tool | FDS (Fire Dynamics Simulator) | NIST 개발, 오픈소스 |
| 후처리 | Smokeview | FDS 연동 시각화 |
| 열방출률 (HRR) | UL 9540A 시험 결과 기반 | Cell → Module → Unit |
| 연소 가스 | HF, CO, CO₂, H₂, Electrolyte vapor | 독성 농도 기준 비교 |
| 메시 크기 | D*/δx = 4 ~ 16 (FDS User Guide 권장) | D* = (Q̇/(ρ∞·Cp·T∞·√g))^(2/5) |
| 시뮬레이션 시간 | 300 ~ 3600 s (시나리오별) | 열폭주 전파 + 소화 + 환기 |

```
S4: 컨테이너| 랙→전체 전파   | 200~2000kW | 30min~2h| 인접 컨테이너 영향·이격거리

```

#### 유독가스 허용 농도 판정 (인명 안전 / Tenability)

| 가스 | IDLH (ppm) | 비고 |
|------|-----------|------|
| HF (불화수소) | 30 | 전해질(LiPF₆) 연소 주생성물, 인명 안전 핵심 지표 — NIOSH IDLH 30 ppm |
| CO (일산화탄소) | 1,200 | 질식·중독 — NIOSH IDLH 1,200 ppm |
| CO₂ (이산화탄소) | 40,000 | 산소 결핍·과호흡 — NIOSH IDLH 40,000 ppm (4 vol%) |
| H₂ (수소) | LFL 4 vol% (40,000 ppm) | Deflagration 위험, 천장 축적 주의 — 폭발하한 기준 |

> 근거: NIOSH IDLH(Immediately Dangerous to Life or Health) 농도. 대피·인원 보호 판정은 **단순 농도 도달 여부가 아니라** ISO 13571 / NFPA 130 의 FED·FEC(Fractional Effective Dose/Concentration) 누적 또는 IDLH 도달 시간(시정·노출시간) 기준으로 정량 평가한다.
> Tenability 합격선 (예): 가시거리 ≥ 10 m (대형 공간 피난), FED ≤ 0.3, HF 노출 < IDLH·도달시간 ≥ 피난소요시간(RSET) + 마진.

#### 환기 / 가스 배출 기준

| 모드 | 환기율 | 목적 / 판정 |
|------|--------|------|
| 정상 환기 | ACH 2 ~ 6 | 외기 도입, 결로 방지 (상대습도 ≤ 60% 유지) |
| 비상 환기 | ACH 10 ~ 20 | 화재 후 가스 퍼지·가연성 가스 배출 (H₂ 농도 < 25% LFL = 1 vol% 유지) |
| Deflagration Vent | NFPA 68 기반 면적 산정 | 폭발 압력(Pred) ≤ 용기/구조 내압 한계(Pes) |
| 배출 방향 | 인원 동선 반대 방향 | 안전 동선 확보 |
| 배출구 위치 | 컨테이너 상부 (경량 가스 H₂·고온가스) | 부력 상승 활용 |

## 해석 모델링 기준

### 난류 모델 선정

| 모델 | 적용 조건 | 정밀도 | 비용 | 비고 |
|------|----------|--------|------|------|
| k-ε (Realizable) | 내부 유동, 자연/강제 대류 | ★★★ | ★★ | BESS 컨테이너 기본 |
| k-ω SST | 벽면 근처, 박리 유동 | ★★★★ | ★★★ | 랙 후면, 장애물 후류 |
| LES (Large Eddy Sim.) | 비정상, 화재, 혼합 | ★★★★★ | ★★★★★ | FDS 기본 모델 |
| Laminar | Re < 2,300, 미세 유로 | ★★★★ | ★ | 액냉 미세 채널 |
| 자연 대류 (Boussinesq) | 밀폐 공간, 저속 | ★★★ | ★★ | 자연 환기 |

> **[정합성 가드레일]** 난류 모델을 세션마다 다르게 선택(k-ω SST vs k-ε Realizable)하고 근거를 명시하지 않는 오류 차단 → 동일 형상에 대한 모델 선정 기준을 고정하고 Re·y+로 근거를 명시한다. (벽 근처 박리·후류가 지배적이면 k-ω SST + y+ < 5, 벌크 혼합이 지배적이면 k-ε Realizable + 벽 함수 y+ 30~100)

### 메시 기준

| 해석 대상 | 요소 타입 | 권장 크기 | y+ 목표 | 비고 |
|----------|----------|----------|---------|------|
| 컨테이너 전체 | Polyhedral / Hex | 10 ~ 30 mm | 30 ~ 100 | 벽 함수 사용 |
| 배터리 랙 주변 | Polyhedral (Prism layer) | 3 ~ 10 mm | 1 ~ 5 | Low-Re 모델 시 |
| 토출구/흡입구 | Hex / Prism | 2 ~ 5 mm | < 1 | 기류 정밀 해석 |
| 액냉 채널 (내부) | Hex | 0.5 ~ 2 mm | < 1 | 채널 높이 대비 10 ~ 20개 |
| FDS 화재 | Rectilinear (균일) | D*/10 ~ D*/5 | — | FDS 전용 메시 (D*/δx = 5~10 권장) |

메시 품질 합격선: Skewness ≤ 0.95, Orthogonal Quality ≥ 0.1, Prism layer 성장률 ≤ 1.2, Aspect Ratio (벌크 영역) ≤ 100.

### Grid Independence Study (GCI)

```
GCI (Grid Convergence Index) 절차 — Roache (1994) / ASME V&V 20-2009:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 3단계 메시 생성 (Coarse / Medium / Fine)
   - 격자비: r = h_coarse / h_fine ≥ 1.3
2. 각 메시에서 대표 물리량 추출 (예: Tmax, ΔP, 평균 풍속)
3. Richardson Extrapolation으로 외삽값(φ_exact) 산출
4. GCI 계산:
   GCI_fine = Fs × |ε| / (r^p − 1)
   Fs = 1.25 (안전 계수), ε = 상대오차, p = 관측 수렴 차수 (이론값: 2)
5. 합격 기준: GCI_fine ≤ 5%, 점근 수렴 확인 (GCI_23 / (r^p·GCI_12) ≈ 1)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 수렴 기준
- 잔차: 연속/운동량 ≤ 10⁻⁴, 에너지 ≤ 10⁻⁶
- 에너지 밸런스: 입열 = 출열 ± 1% 이내 (불일치 > 1% → 재수렴/메시 점검)
- 모니터링 변수(Tmax, ΔP, 출구온도) 변동폭 < 0.5% (정상 상태 도달 판정)
