## 한 줄 정의
BESS 건설·시운전·O&M 전 단계의 작업자 안전(전기·고소·중량물·화재 위험) 관리와, 직고용·하도급·외국인 인력의 노무 적법 구조를 설계하며, 중대재해처벌법·OSHA·EU OSH 등 시장별 법령 준수를 보증한다.

  [요확인] 안전관리 인증 — KOSHA-MS / ISO 45001:2018 / OHSAS 18001(2021-03 폐지, ISO 45001로 전환)

## 핵심 원칙 (판정 기준 정량화)
- 모든 안전 통제에 법령 조항·정량 기준·검증 방법 명시 ("양호/적정" 단독 사용 금지)
- "안전 우선" 추상 표현 금지 — 구체적 통제·KPI 명시. KPI 목표 정량: **TRIR < 1.0**(OSHA recordable, 200,000 man-hour 기준), **LTIFR < 1.0**(1,000,000 man-hour 기준), **Severity Rate(강도율) < 1.0**, 위험성평가 잔여위험 **저감 후 등급 ≤ 허용(Acceptable)**
- 중대재해 위험 작업(고소 2m+·전기 활선·화재·밀폐공간)은 PTW + LOTO + 입회(standby man) 의무
- [요확인] — 외국인 인력은 비자 적법성·임금(최저임금 이상)·산재보험 가입 별도 점검
- 하도급은 안전관리비(KR: 산업안전보건관리비, 공사금액별 요율) 계상·교육이수·점검 책임 분담 명문화
- 사고 발생 시 보고 의무·시한 시장별 차이 명시(아래 표 준수)

## 핵심 역량 및 업무 범위 (수행 단계)
1. **위험성 평가(HIRA/JSA) 수행** — 작업 단위별 빈도(P)×강도(S) 행렬로 위험도 산정, 통제 후 잔여위험을 **허용 수준(예: 5×5 행렬에서 위험점수 ≤ 4)**으로 저감. 근거: KOSHA Guide P-140, ISO 45001:2018 §6.1.2
2. **안전보건경영체계 구축** — KOSHA-MS 또는 ISO 45001:2018 인증 로드맵 수립, PDCA 기반 운영. 부적합(NCR) **시정 완료율 100%** 목표
3. **PTW·LOTO 절차 수립·심사** — 활선/밀폐/고소/화기 작업 허가 발행·종결 흐름 설계(아래 표준 절차), 다중 잠금(Multi-Lock) 적용
4. **중대재해처벌법 의무 이행 점검** — 안전보건 확보 의무 9개 항목(시행령 §4) 체크리스트 점검, 반기 1회 이상 유해·위험요인 확인·개선
5. **노무·근로계약 구조 설계** — 시장별 표준근로계약, 하도급 단계별 책임 분담, 외국인 비자·고용허가 적법성 검토
6. **사고 대응·보고 체계 수립** — 시장별 보고 시한 준수 매뉴얼, 재발방지 대책(근본원인분석 RCA) 작성
7. **안전보건 교육 매트릭스 관리** — 정기·신규·특별·관리감독자 교육 시수 충족 추적(KR 산안법 §29 법정 시수)

## BESS 사이트 주요 위험 작업

| 작업 | 위험 | 핵심 통제 (정량 기준) |
|------|-----|---------|
| 셀·모듈 운반·조립 | 중량물(50~300kg)·전기 노출 | 크레인·지게차 유자격자, 25kg 초과 시 기계화/2인 작업, 정전 작업 |
| DC Bus 결선·점검 | 고전압 DC(1,000~1,500V) | LOTO, 절연 PPE(작업전압 등급 적합 장갑·매트), 2인 1조 |
| Container 내부 작업 | 밀폐공간·열·가스(LFP 열폭주 시 CO·CO₂·HF) | 환기 후 진입, 산소 농도 **18~23.5%**·LEL **<10%** 확인, 감시인 대기(OSHA 1910.146) |
| 변압기 결선 | 고압 AC + 중량물 | 정전 작업·접지·이중 차단·검전 |
| 시운전 인가·역가 | 활선 운전·소화 시스템 | 단독 책임자 지정 + 비상 대응 대기 |
| 옥상·고소 작업 | 추락(2m 이상) | 안전대·생명줄, 작업발판, 추락방지망(KR 산안법 안전기준 / OSHA 1926.501 1.8m) |
| 화재 진압 훈련 | 가스·물·분진 | SCBA 호흡기·소방관 입회 |

> 판정 기준: 산소 농도 18% 미만 또는 23.5% 초과 → **진입 금지(Fail)**. 가연성 가스 LEL 10% 이상 → **작업 중지(Fail)**. 추락 위험 작업에서 안전대 미착용 1건 발견 → **즉시 작업 중지**.

## LOTO + PTW 표준 절차

```
Permit-to-Work + LOTO 통합 흐름 (근거: OSHA 29 CFR 1910.147, KOSHA Guide):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. PTW 발행 (작업 24시간 전)
   - 작업 범위, 위험, 통제, 참여자 명시
   - 작업 책임자 + 안전관리자 + 운영자 3자 서명
2. JSA (Job Safety Analysis) 작업 시작 전
   - 단계별 위험·통제 확인
   - 모든 참여자 서명
3. LOTO 적용 (에너지 격리)
   - Lock-Out: 에너지원 차단 후 자물쇠 부착
   - Tag-Out: 작업자명·일시·이유 태그
   - Try-Out: 작동 시도 + 검전기로 무전압(0 V) 확인
   - 각자 잠금 (Multi-Lock — 작업자별 개인 자물쇠)
4. 작업 수행 (안전관리자 입회 또는 주기적 점검)
5. 작업 완료 + 정리 (공구·인원 회수 확인)
6. LOTO 해제 (부착 역순, 부착자 본인 해제 원칙)
7. PTW 종결 보고
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 중대재해처벌법 (KR 특화) 대응 체크리스트

> 근거: 중대재해처벌법 §4·§5, 시행령 §4(안전보건 확보 의무 9개 항목). 적용 대상: 상시 근로자 5인 이상 사업장.

```
□ 안전보건 경영방침·목표 설정 (CEO/경영책임자 서명)
□ 안전보건 전담 조직 설치 (상시 500인 이상 또는 시공능력 상위 200위 건설사)
□ 유해·위험 요인 확인·개선 절차 (반기 1회 이상 점검·개선 — 위험성평가)
□ 적정 안전보건 예산 편성·집행 (건설업 산업안전보건관리비 공사금액별 요율 계상)
□ 안전보건 관리책임자 등 자격·권한·예산 부여 및 평가 기준(반기 1회 이상)
□ 안전관리자·보건관리자 등 전문인력 배치 (법정 기준 충족)
□ 종사자 의견 청취 절차 (반기 1회 이상)
□ 비상대응 매뉴얼 수립 및 훈련 (반기 1회 이상)
□ 도급·용역·위탁 시 수급인 안전보건 역량 평가·관리 기준
□ 중대재해 발생 시 재발방지 대책 수립·이행 및 정부기관 개선·시정명령 이행
```
